# Cosmea

Учебный интернет-магазин косметики на Angular 22 и Tailwind CSS 4.

## Возможности

- Каталог с поиском, фильтрами, сортировкой и пагинацией.
- Карточки товаров, галереи и быстрый просмотр на компьютере.
- Корзина, избранное и история успешных поисковых запросов.
- Адаптивный интерфейс и нижняя навигация на телефоне.

Данные товаров находятся в коде. Корзина, избранное и история поиска сохраняются в localStorage браузера. Серверная часть, база данных и реальные платежи отсутствуют; оформление заказа демонстрационное.

## Требования

- Node.js 24.15 или новее в ветке 24 (проект проверялся с Node.js 24.20).
- npm, который устанавливается вместе с Node.js.
- Интернет для установки зависимостей, загрузки фотографий и шрифтов.

## Установка и запуск

Скопируйте HTTPS-ссылку в меню **Code** репозитория и выполните:

```bash
git clone <HTTPS-ссылка-репозитория>
cd cosmea
npm ci
npm start
```

Откройте http://localhost:4200/. Оставьте терминал работающим, пока пользуетесь сайтом. Для остановки нажмите Ctrl+C.

Чтобы браузер открылся автоматически:

```bash
npm start -- --open
```

Глобально устанавливать Angular CLI не требуется. Для приватного репозитория владелец должен предоставить доступ к репозиторию, а получатель — принять приглашение и авторизоваться в GitHub при клонировании.

## Production-сборка

```bash
npm run build
```

Результат находится в `dist/cosmes/browser`.

## Браузерные проверки

```bash
npm run test:e2e
```

Тесты запускают Google Chrome без видимого окна и проверяют десктопный и мобильный интерфейсы. Тестовый сервер на порту 4201 запускается автоматически.

Проверяются корзина, история поиска, возврат в каталог с сохранением позиции, карусель, быстрый просмотр, мобильное меню и фильтры.

Если Google Chrome не установлен, установите Chromium:

```bash
npx playwright install chromium
```

Затем укажите `PLAYWRIGHT_CHANNEL=chromium` в окружении. Например, в PowerShell:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chromium'
npm run test:e2e
```
